## Operating principles

The public website identifies these principles:
- People first: build around real human needs.
- Explainable by design: make decisions easier to understand.
- Built to connect: create products that work better together.
- Responsible AI: value explainability, human oversight, privacy, and fairness.
- Access: account for different languages, contexts, devices, and connectivity.
- Long-term thinking: build carefully, learn from real use, and improve over time.
